# trabalho_cesar_machine_learning_ric
Trabalho da disciplina de Aprendizado de Máquina da pós-graduação de OPEN RAN - Tecnologias emergentes, da CESAR School.

## Estrutura do repositório

O repositório contém:

- **dataset:** diretório com os conjuntos de dados utilizados no trabalho;
- **requirements.txt:** manifesto de dependências Python;
- **trabalho_ia_sutd.ipynb:** IPython notebook com código mesclado com documentação em Markdown;
- **trabalho_ia_sutd.pdf:** Relatório PDF exportado a partir do notebook IPython;

## Instruções de execução

- Instalar dependências com `pip install -r requirements.txt`;
- Abrir o notebook em um ambiente de execução de notebooks IPython (Jupyter Notebook, *e.g*);
- Executar todas as células do notebook, ou uma por vez
